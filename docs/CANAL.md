# Canal del equipo

Este PR **no se mergea nunca**. Es el canal de comunicación del equipo: todo se habla en sus comentarios.

## Cómo usarlo
- **Avances:** qué terminaste y el link a tu PR.
- **Bloqueos:** qué te frena y a quién necesitás. Mencioná con @usuario.
- **Decisiones:** si se decide algo (idea, red, contratos, direcciones), dejalo escrito acá.
- **Datos útiles:** direcciones de contratos, links de Snowtrace, billeteras de prueba (NUNCA claves privadas).

## Horarios clave
- 18:00 entrega (confirmar con la organización).
- Antes de la entrega: repo público, contrato verificado, demo y README completo.
